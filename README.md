# Calculadora de figuras geométricas

Calcula el **perímetro y el área** de figuras planas, y el **área superficial y el volumen** de sólidos regulares.

## Archivos

| Archivo | Qué es |
|---|---|
| `index.html` | Versión web. Se abre en cualquier navegador o se publica con GitHub Pages. |
| `calculadora_figuras.py` | Versión en Python para la terminal (Visual Studio Code). |

## Figuras incluidas

- **Planas:** cuadrado, rectángulo, triángulo equilátero, círculo, polígono regular de n lados.
- **Sólidos:** cubo, tetraedro, octaedro, dodecaedro, icosaedro, esfera, cilindro, cono.

## Cómo funciona

1. Se elige la figura.
2. Se ingresa la unidad de medida (obligatoria: mm, cm, m o km) y las medidas.
3. Se muestran los resultados con su unidad (u, u², u³).
4. El programa pregunta "¿Quieres realizar otra consulta?" (sí: vuelve al menú; no: termina).

## Ejecutar la versión Python

```bash
py calculadora_figuras.py
```

## Publicar la versión web en GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
